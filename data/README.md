# Data Directory

This directory holds static JSON schemas, role profiles, tagged question banks, and SQL seed datasets (populated in Phase 2):

- `schemas/` — JSON Schemas for role profiles and question banks.
- `roles/` — One JSON role profile per role (`fresh`, `senior`, `pm`, `dev`, `sa`, `qa`, `dba`).
- `questions/` — Tagged question banks per role.
- `datasets/` — SQL seed datasets verified against reference solutions in CI.
